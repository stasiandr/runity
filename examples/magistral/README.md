# Магистраль

Железнодорожный роуглайк-деккилдер на scrap. Боёв нет: карты прокладывают
пути и пускают поезда, поезда сами возят уголь, руду, зерно и сталь и
приносят деньги, а в конце каждого этапа банк требует платёж по кредиту.
Не хватило — банкрот, забег окончен.

```
cargo run --release                                  # играть
cargo test                                           # правила, экран, картинка в target/shots/
cargo run --release -p magistral-rules --bin depth   # отчёт по глубине
```

## Правила

* **Карта** 8×8 по сиду: река посередине (через неё — только «Мост»),
  холмы («Тоннель»), места. Город с вокзалом — на западном берегу, рядом
  уголь и ферма. Завод, руда, второй город и второй уголь — за рекой.
* **Ход**: рука до 5 карт, 3 бригады. Путь тянется от сети к выбранному
  месту, станция ставится у места рядом с путём, поезд ходит между двумя
  станциями: грузится на одной, продаёт на другой.
* **Грузы**: город покупает уголь (1), зерно (2) и сталь (5), завод —
  уголь и руду (по 1) и делает из пары сталь. За каждые 4 клетки маршрута
  +1 монета с единицы.
* **Контракты**: видно три, действует первый; выполнил к сроку — награда.
* **Этап** — 8 ходов, потом платёж: 10, 24, 42, 66, 96. Между этапами —
  биржа: взять одну из трёх карт и выкинуть одну из колоды за 5.

Все числа — `content/magistral/core/rules.ron`.

## Как играть

Нажмите карту в руке — подсветятся клетки, куда её можно сыграть, — и
нажмите клетку. Поезд — две станции подряд. «Диспетчер» — сначала поезд
в списке справа. «Совет ИИ» показывает, что сделал бы поиск на 300
партий, «Ход ИИ» делает это за вас.

## Глубина

Игру проектировали так, чтобы игрок, который смотрит дальше, выигрывал
заметно чаще жадного. Это меряет `depth`: лестница игроков на одних и тех
же сидах — случайный, «быстрый» (грубые приоритеты), жадный (то, что даёт
больше денег за этот и следующий ход) и поиск по дереву (ISMCTS: каждая
итерация заново угадывает скрытое — порядок колоды, будущие контракты).
Ступень засчитывается, если старший игрок обыгрывает младшего хотя бы на
60% сидов. Код игроков — `rules/src/ai.rs`.

Результаты последнего прогона — в [DEPTH.md](DEPTH.md).
