# Материалы-примеры

Палитра движка в виде ассетов (материалы лежат по фичам: `nature/`, `water/`, `camp/`…). Те же цвета, что зашиты в
`scrap::material::builtin`, плюс `moss`, которого среди builtin-ов нет — он и
показывает, зачем это нужно: имя материала здесь принадлежит проекту, а не
движку.

Цвет пишется в sRGB-шестнадцатеричном виде — так его выдаёт любая пипетка и
любой скриншот. Перевод в линейное пространство делает импорт, один раз.
Линейную тройку тоже можно написать: `color: (0.14, 0.20, 0.09)`.

```sh
cargo run -p scrap-cli -- sync examples/valley
cargo run -p scrap-engine --example scene_shot -- examples/valley/content/valley/maps/first-light.scene.ron
```

Вторая команда рисует ту же сцену, но имена материалов в ней теперь
разрешаются через библиотеку проекта, а не через builtin-ы: `scene_shot`
находит проект по сцене и берёт его `library/`. Поменяйте шестнадцатеричный
код, перезапустите обе команды — и увидите новый цвет. Это и есть цикл, для
которого материал стал ассетом.
