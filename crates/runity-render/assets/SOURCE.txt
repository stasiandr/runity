The hinted build, unmodified. TrueType outlines (glyf/loca), 2048 units
per em, 3387 glyphs; covers Latin, Cyrillic and Greek, which is what
tests/font_embedded.rs pins down. Kerning lives in GPOS, so Font::kerning
answers zero for it — the kern-table path is exercised by synthetic fonts
in src/font/fixture.rs instead.

It is compiled into the library by include_bytes! (see Font::embedded), so
the file's size is the binary's size: about half a megabyte.
