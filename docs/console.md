# Консоль, читы и отладка над вещью — как в Unreal

Карточка к пункту 4 обзора инструментов дизайнера
(`docs/history/2026-09-designer-tools-review/`, записки
`designers_data_debug.md` §2).

Самые ходовые отладочные инструменты дизайнера — невзрачные: консоль в
игре, читы и надпись над вещью «что она сейчас делает». В Unreal это всё
есть из коробки: консоль `~` с CVars и CheatManager, Gameplay Debugger на
апострофе. В Unity нет ничего, поэтому живут SRDebugger, IngameDebugConsole
и Graphy. Нужда общая, разница только в том, кто её закрывает. У scrap
было два куска: `Tuned<T>` (числа из `tuning/` перечитываются на ходу) и
Console редактора, которая только читает вывод игры. Не хватало обратного
пути — сказать игре что-то словами.

## Что берём

1. **Команды (Unreal: console commands, CheatManager).** `Commands` в ядре
   (`scrap_core::console`): имя → функция `fn(&mut World, &[&str]) ->
   Result<String, String>` и строчка помощи. Чит — это просто команда игры.
   Движок приносит три своих: `help`; `get world.gravity`, чтобы прочитать
   число из `tuning/world.ron`; `set world.gravity -3`, чтобы поменять его
   **в файле**. Меняется только текст этого значения (`ron_edit::set_at`),
   комментарии остаются, `Tuned::poll` подхватывает правку, как сохранение
   из редактора текста. Слово вместо числа не пройдёт, файл, который
   перестанет читаться, тоже; тип игры проверяет сам `Tuned` и остаётся на
   старых числах, если правка не подошла.
2. **Консоль в игре (`~`).** `scrap::console::Console`: строка поверх
   игры на `scrap-overlay`. UI игры пока живёт там: этап 4 docs/ui.md не
   сделан. Открывается действием `console` (в шаблонном `input.ron` это
   backtick). Enter выполняет, Up/Down листают набранное раньше, Tab
   дописывает имя, Escape закрывает. Пока консоль открыта, клавиши не
   достаются игре (`has_keyboard`: Escape не выходит из игры, F3 не
   переключается). Каждая строка печатается как `> строка` и отступом
   ответ, так что в Console редактора это одна запись.
3. **Из редактора в игру.** Под Console в студии есть поле: строка уходит
   игре во вкладке Game по сокету встраивания (`ToGame::Command`), shell
   отдаёт её кадру (`Context::commands`), консоль выполняет, ответ
   приходит обратно через вывод игры. Для агента — MCP `game_console`:
   отправить строку и дождаться записи с ответом. Сессия:
   `send_game_command`, `game_console`.
4. **Отладка над вещью (Gameplay Debugger, облегчённый).**
   `scrap::debug_overlay::DebugOverlay`, действие `debug` (апостроф, как в
   Unreal). Берётся вещь, ближайшая к центру вида: имя и ID, где стоит,
   тело, чья она по сети, состояние аниматора и сохраняемые компоненты —
   тот же снимок, что Inspector показывает полями `game.*`
   (`Components::write_saved`). Её коллайдер обводится линиями поверх всего
   (`overlay_draws`). Пока отладка выключена, она не стоит ничего.

В шаблоне всё это уже подключено: поля `console` и `debug` у `Game`,
функция `cheats()` с живым примером (`spin 90` — всё, что крутится,
крутится с этой скоростью) и две строки в `input.ron`.

## Чего не берём и почему

* **CVars — отдельные переменные движка.** У нас уже есть одна правда для
  чисел — `tuning/` (постулат 7). `set` правит её, а не заводит второй
  реестр значений, живущий только в памяти.
* **`set` только для этого запуска (`--temp`).** Правка в файле — одна
  строка диффа: нужна — коммитишь, не нужна — `git checkout`. Второй путь
  повторил бы беду Unity: подкрутил во время игры, остановил — и всё
  пропало. Временное, что правда нужно (бессмертие, полёт), игра делает
  своим читом.
* **`spawn`, `tp`.** `spawn` требует рендера и библиотеки, а у
  команды есть только мир. `tp` зависит от того, кто в игре игрок, — это
  чит конкретной игры, а не движка.
* **Категории Gameplay Debugger (AI, BT, EQS, GAS) и история (Visual
  Logger, Rewind Debugger).** Это следующая ступень, «состояние во
  времени». Сейчас — «увидеть» и «поменять».
* **Консоль в релизе по умолчанию.** Unreal вырезает читы из shipping
  (`ECVF_Cheat`). У нас консоль включена в debug-сборке и там, где задан
  `SCRAP_CONSOLE=1` (сборка для плейтестера). Выключенная ничего не
  рисует, не берёт клавиш и отвечает редактору, что она выключена.

## Ответы постулатам

1. **Скорость итерации.** Число меняется одной строкой в игре или в
   Console редактора, без переключения в текстовый редактор; `Tuned`
   подхватывает его за четверть секунды. Команды — обычные функции игры,
   горячий патч до них доходит. Оговорка: `Commands` хранит указатели на
   функции, так что после патча работает старое тело команды, пока её не
   зарегистрируют заново. Так же сейчас устроен `PlayerLoop`.
2. **Git.** `set` оставляет дифф в одну строку: только значение, без
   переформатирования файла. Сама консоль и история набранного на диск не
   пишутся.
3. **Модульность.** Реестр лежит в ядре рядом с `Tuned` и `ron_edit`: он
   нужен и headless-серверу, у которого нет UI, и сокету встраивания,
   который тоже в ядре. Консоль и отладочный оверлей — в фасаде `scrap`:
   им нужны overlay и рендер. Выключаются одной строкой в `main.rs` — не
   создавать поле. Спорный момент: по трём проверкам ядра реестр ядру
   самому не нужен. Держим его там, пока он маленький и без зависимостей;
   если обрастёт, переедет в модуль.
4. **Сеть.** Команда выполняется у того, кто её набрал, над его миром.
   Чит по чужой вещи меняет реплику, и владелец перезапишет её следующим
   снимком. Поэтому читы, которые должны видеть все, игра пишет через свои
   сетевые события. `set` меняет файл, а файл `tuning/` на машине у
   каждого свой: у четырёх друзей на четырёх машинах изменится только у
   набравшего. При нескольких игроках из редактора команду из Console
   получает только хост (вкладка Game), окна остальных её не получают.
   Консоль по сети — не сейчас. Над вещью видно «owned here» или «a
   replica».
5. **AI.** `game_console` — агент без дисплея отправляет чит или `set` и
   получает ответ текстом; ошибка тоже приходит словами («world.gravity is
   a number, and `fast` is not»). Всё проверяется тестами без окна: реестр,
   разбор, минимальная правка файла и перечитывание `Tuned`, строка по
   сокету с ответом из вывода, MCP.
6. **Производительность.** Закрытая консоль — одна проверка на кадр.
   Оверлей стоит только когда включён: проход по сущностям с ID и
   проекция на экран (O(n) в кадр отладки), описание одной вещи. Меш линий
   загружается один раз.
7. **Opinionated.** Одна клавиша, один синтаксис, один способ поменять
   число — файл. Читы — функции, без атрибутов и рефлексии.
8. **Батарейки.** Из коробки в шаблоне: консоль, `help/get/set`, пример
   чита, отладка над вещью, поле в Console редактора.

Открытые вопросы DNA.md не затронуты: генераторы игры (вопрос 9) здесь ни
при чём.
