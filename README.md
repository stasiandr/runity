# runity

Игровой движок.

Игрового кода здесь нет: движок проверяется на собственном — встроенных
мешах и материалах, примерах ассетов и примерах сцен. Дизайн игры, ради
которой всё затевалось, лежит в [docs/design/](docs/design/) — тринадцать
документов, от мира и поселенцев до экономики и того, как это выглядит. Они
задают, куда движок растёт.

## Принцип

Берём готовое. Своё пишем там, где упёрлись в потолок готового, а не заранее.

Так было не всегда: до этого движок собирался из одного `std`, без единой
сторонней зависимости — свой растеризатор, свой PNG, свой X11 по проводу.
Тот эксперимент закончен, и его код лежит в истории git. Чем именно его
заменили и почему — [docs/stack.md](docs/stack.md).

## Раскладка

```
crates/runity          движок: сцена, ассеты, устройство, рендер, встроенное
crates/runity-import   импорт исходных форматов в формат движка (в игру не линкуется)
scenes/                примеры сцен, на которых всё проверяется
scenes/prefabs/        префабы к ним
assets/examples/       примеры моделей и текстур (Kenney, CC0) и палитра материалов
docs/design/           дизайн игры, ради которой движок и делается
docs/stack.md          на чём и почему
```

## Посмотреть на кадр

```
cargo run --release --example scene_shot -- scenes/first-light.ron -o frame.png
```

Референсная сцена открывается без библиотеки и без импорта — все модели в ней
встроенные, так что это самый короткий путь от `git clone` до картинки. В ней
земля, четыре дерева на разных дистанциях (туман), куб (полушарный ambient на
трёх гранях), сфера (нормали) и один неосвещаемый уголёк.

## Походить внутри

```
cargo run --release --features desktop-shell --example walk -- scenes/first-light.ron
```

WASD ходит, левая кнопка мыши крутит голову, Escape выходит. Единственная
часть движка, которую CI не может выполнить — у раннера нет дисплея, — поэтому
она хотя бы проверяется типами отдельным шагом.

## Префабы

Вещь, собранная один раз, ставится много раз. Префаб — это одно поддерево
сущностей в своём файле (`scenes/prefabs/campfire.prefab`), а сцена ссылается
на него по имени:

```
(name: "west fire", model: "", prefab: "campfire", transform: (position: (-3.2, 0.0, 0.0)))
```

Экземпляр задаёт имя, место и, если надо, материал и физику корня; всё
остальное приходит из файла. Поправьте префаб — поменяются все экземпляры
сразу. Префабы ищутся в каталоге `prefabs/` рядом со сценой: и `scene_shot`,
и `walk`, и редактор смотрят туда, поэтому все трое показывают одно и то же.

```
cargo run --release --example scene_shot -- scenes/camp.ron -o camp.png
```

Переопределений глубже корня пока нет — «у этого костра третий камень
повёрнут» не выразить. Это самая сложная часть системы префабов в Unity, и
делать её наугад хуже, чем не делать; когда понадобится — проектировать под
живую сцену.

## Кадр без видеокарты

Движок рисует на машине без дисплея и без графической карты — через
программный Vulkan. Это и есть то, на чём держатся CI, golden-кадры и любая
петля, где что-то меняется и надо посмотреть на результат.

```
cargo test --workspace
```

На Linux нужен программный драйвер: `sudo apt-get install mesa-vulkan-drivers`.
На macOS всегда есть Metal, на Windows — WARP. Если адаптера нет вообще, тест
говорит об этом одной строкой и пропускается.

## Ассеты

Ничего, что грузит игра, не является исходным форматом. Исходник импортируется
один раз, дальше движок открывает только своё:

```
cargo run -p runity-import -- assets/examples/models/pine_large.obj --library library
cargo run --release --example scene_shot -- my-scene.ron --library library
```

Понимает `.gltf`/`.glb` (то, чем экспортируют настоящие инструменты), `.obj`,
растровые картинки, `.wav` и `.rmat`. Узлы сцены glTF при этом обходятся: модель,
собранная из расставленных частей, остаётся собранной.

Материал — такой же ассет, как модель. `.rmat` — это цвет в sRGB-шестнадцатеричном
виде (`(color: "#697c55")`), перевод в линейное пространство делает импорт. Сцена
называет материал по имени, и это имя ищется сначала в библиотеке, потом среди
встроенных: один `#697c55` на весь проект вместо двадцати, разъезжающихся по
девятнадцати сценам. `builtin:stone` — если нужен именно встроенный.

```
cargo run -p runity-import -- assets/examples/materials/*.rmat --library library
```

Рядом с `.rasset` ложится `.rimport` — из чего и с какими настройками он
собран, текстом. Без этого импорт был бы дорогой в одну сторону.
